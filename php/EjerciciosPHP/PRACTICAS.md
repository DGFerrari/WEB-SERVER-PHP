Ejercicio 1: Crea una página web con un formulario simple que permita buscar productos por su nombre utilizando el método GET.

REQUISITOS PARA COMPLETAR CORRECTAMENTE EL EJERCICIO:

La página mostrará el mensaje “producto no encontrado” en caso de que el campo esté vacío. De lo contrario, deberá de mostrar la información introducida.
Para que esto funcione, en la página debe de existir información de productos, la información que se mostrará es: código de producto y nombre de producto
El proyecto debe de estar formado por dos páginas: index.php -   getProductos.php


 

Ejercicio 2

-       Crea una página web con un formulario simple que permita introducir el nombre y apellido de un alumno utilizando el método POST. Cuando el usuario envíe el formulario (es decir, deberá de existir un submit, Enviar), el nombre y el apellido del alumno será enviado en la URL y una nueva página mostrará el resultado.

-       REQUISITOS:

-       Crear una página web datosAlumno.php que contenga un formulario con un campo de texto para ingresar el nombre y el apellido del alumno.

-       Crear una página web datosIntroducidos.php que contenga el formulario para mostrar la información del alumno. Esta página, mostrará “Alumno no introducido” en caso de que los campos estén vacíos.
